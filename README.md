# 🧠 AI Project Architect (Desktop GUI Version)

An AI-powered system that turns your short project brief into structured technical tasks and working code snippets — coordinated by specialized AI agents.

This version uses **Tkinter** for a desktop GUI (no browser required).

## 🚀 Quick Start

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your OpenAI API key in .env
python app.py
```
